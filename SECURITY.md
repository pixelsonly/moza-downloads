# Security Policy

## Reporting a vulnerability

Please don't report security issues in public issues. Use GitHub's
[private vulnerability reporting](https://github.com/pixelsonly/moza-downloads/security/advisories/new)
instead, or email [hello@pixelsonly.racing](mailto:hello@pixelsonly.racing).

Relevant issues include problems in the release workflows (for example, a way to tamper with
a published `.zip`) or a dashboard file that could harm a wheel or the software that loads it.

You'll get an acknowledgement within a few days. Fixes ship as a new release of the affected
dashboard.

## Supported versions

Only the latest release of each dashboard is supported.
